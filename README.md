# Combination Generator

מחולל תמורות (Permutations) של 1..N עבור N בין 1 ל-20.
Backend ב-.NET 8, לקוח ב-Angular 20.

## דרישות מקדימות
- .NET 8 SDK

## הרצת ה-Backend
```
dotnet build
dotnet run --project src/Backend/CombinationGenerator.Api
```
השרת עולה בכתובת http://localhost:5080

(המסמך יושלם בהמשך: הרצת הלקוח, בדיקות וקונפיגורציה.)
